# QA Inventory — posture-ai

Phase 1 checklist for PASS-09, reconciled with the current `app/**/page.tsx` tree after Array v4 (PR #165, `784cffa`). One row is one screen or user-facing behavior; a row may name a supporting API. Route groups are omitted from URLs. Historical verdicts remain in `docs/qa/passes/`; the PASS-09 column is intentionally blank until the next user-level pass.

**Roles:** practitioner = signed-in clinician account; consent-token = holder of a consent link; share-token = holder of a workout share link; anonymous = no session; athlete = invited training account. Multiple roles in one cell mean each relevant view or denial is in scope. AC = observable acceptance criterion. E = edge case, ordered highest risk first. `RETIRED` rows preserve removed behavior and are excluded from the next pass.
