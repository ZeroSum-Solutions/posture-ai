# Original exercise media capture proposal

Status: prepared for review; no filming, spending, rights approval or catalog activation has occurred. This addresses the concrete sourcing/filming proposal required by the approved strength-and-conditioning PRD after the starter media inspection.

The inspected third-party squat and row candidates show different exercise variants, and the floor-press asset lacks complete attribution. The shortest remaining route to consistent exact-variant media is a small original shoot with one demonstrator, one background and one camera setup. Existing usable reference assets can remain reference-only while the original set is prepared.

## First capture set

| Programmed movement | Required visible setup | Required coverage |
| --- | --- | --- |
| Goblet squat | One dumbbell held with both hands at the chest; both feet flat on the floor; no heel-elevation prop | Standing setup, controlled descent and return; both feet and the implement visible throughout |
| Dumbbell Romanian deadlift | One dumbbell in each hand, two implements total, unsupported bilateral stance | Upright setup, hip hinge and return; feet, trunk and both implements remain in frame |
| Dumbbell bent-over row | One dumbbell in each hand, two implements total; no bench or hand support | Setup and a complete pull/return; view must show the unsupported stance and both implements |
| Dumbbell floor press | Two dumbbells; back supported by the floor rather than a bench | Floor setup and complete lower/press sequence, with both implements visible |
| Walking | Level unobstructed surface; no treadmill assumed by the program | A continuous side view showing several complete steps |

These are media identification requirements, not technique approval or a load prescription. A qualified exercise reviewer must approve the demonstrated movement against the exact authored exercise version before it becomes automatic-program media.

## Consistent presentation

Use a plain background, even lighting and clothing that keeps the relevant movement visible. Keep the whole person and equipment inside the frame with spare room for narrow screens. Record clean natural movement without overlaid claims, timers or medical labels. Capture a standing/setup still and an end-position still from the same recording, so a still-image fallback remains consistent with playback. Review the crop inside the existing exercise card and player at both narrow and desktop widths before exporting final assets.

## Records needed before use

For each recording, retain its source file identity, creator credit, demonstrator permission record, permitted application/commercial use, exact exercise-version mapping, reviewer identity/date and review disposition. Store the final asset hash and its attribution with the media record. Record any crop or edit as a derived asset associated with the original. These records are inputs to the existing rights/review process; this proposal supplies none of the missing approvals.

No new media service or paid asset purchase is required to prepare this set. A filming date, demonstrator, creator and qualified reviewer still need to be named. Cost and availability are unknown; no budget or booking is assumed. The existing app can continue to show its attributed reference/fallback presentation while this work is arranged.
